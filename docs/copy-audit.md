## 边界判断（请拍板）

1. **ui/app.js:3155 记忆编辑 hint**「密钥、密码和 token 会被自动过滤为 [REDACTED]。」——描述系统对用户输入的处理规则，用户需要知道写入内容会被脱敏才算完整规则信息；我倾向保留不动，仅 `[REDACTED]` 字样偏实现味。
2. **ui/app.js:2059 进化页空态**「Bot 可以提交自我改进建议，但无法自行批准。」——后半句说明权限边界，算规则信息；但「无法自行批准」接近向用户复述机制。若判 A，可替换为：「新建提案即可开始。」
3. **ui/app.js:2472 微信扫码 hint**「手机上确认后此处会自动变为已连接。」——描述显而易见的扫码流程结果，但有安抚作用；若判 A 可删句，仅留「微信扫码授权 ClawBot」。
4. **ui/app.js:2590/2777 生产目录 hint**「切换后已有密钥会自动迁移并清理旧目录」——「自动迁移并清理」是行为承诺（用户关心数据不丢），不完全是元信息；倾向保留。
5. **ui/app.js:2971 新建任务 usage-note**——前半句解释表单项的实际效果（父子只影响展示、不影响调度），用户不猜会误解，倾向保留。
6. **ui/app.js:2495 密钥管理 hint**「密钥加密存储」——机制描述但有安全安抚价值；倾向保留。
7. **ui/app.js:2302 用量页 note**「N 次运行的用量记录对不上，数据可能不完整。」——「记录对不上」是内部对账结果，但传达了「数据可能不完整」这一用户需要的警示；倾向保留原文或改「N 次运行的用量数据可能不完整」。
8. **ui/app.js:2075 进化页提案卡「灰度 …」**——灰度发布属部署机制术语，但用户需要知道提案只部分生效；若判 B 可改「部分生效中 …」。
9. **ui/app.js:2603 归档项目 hint**「移除追踪会清理本项目的管理数据」——「管理数据」含义模糊但属删除范围警示；倾向保留。
10. **ui/app.js:609/682「DSH 原生 Web 界面」**——指向宿主产品名，属导航信息；倾向保留。
